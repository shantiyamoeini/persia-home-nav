# Persian Realty Hub

Create the complete UI/UX for a Persian RTL, mobile-first real estate agent app. Include fully navigable screens: Dashboard (today follow-ups, recent properties/clients, quick add actions); Properties (search, Sale/Rent filters, detailed cards); Add Property form with all specified fields; Clients (search and cards); Add Client form; Follow-ups (today, upcoming, completed and mark completed). Use clear Persian labels, a modern clean professional design, consistent components, and a bottom navigation bar. Focus on polished front-end UI and demo data; make all navigation and primary interactions work.
